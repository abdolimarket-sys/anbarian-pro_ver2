فاز ۲۱ حسابداری انبارین

1) ابتدا از نسخه فعلی برنامه و داده‌های آن پشتیبان بگیرید.
2) محتویات پروژه را در محیط توسعه جایگزین کنید؛ فایل‌های داده کاربر را حذف نکنید.
3) npm install
4) npm test
5) npm run typecheck
6) npm run build
7) نسخه آزمایشی را در مرورگر و APK روی دستگاه جداگانه بررسی کنید.

صفحه «حسابداری» به منوی پایین اضافه شده است. برای نخستین بار کدینگ پیشنهادی پایه به‌صورت خودکار ایجاد می‌شود. تمام مبالغ در IndexedDB به ریال ذخیره می‌شوند.
