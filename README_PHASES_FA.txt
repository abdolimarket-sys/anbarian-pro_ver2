نسخه یکپارچه سورس انبارین پرو

این بسته، سورس کامل پروژه بر اساس آخرین درخت پروژه موجود در این گفتگو است.
تغییرات یکپارچه‌شده در این نسخه:
- اصلاح امن نمایش نام محل‌ها در رابط کاربری
- آماده‌سازی معماری مجوزهای محلی (بدون احراز هویت سروری)
- سخت‌سازی اعتبارسنجی و نشست همگام‌سازی تیمی
- بهبود ذخیره‌سازی، چرخش نسخه پشتیبان و بازیابی داده‌ها
- یکپارچه‌سازی گردش‌کار GitHub Actions؛ فایل build.yml تکراری حذف شده و main.yml باقی مانده است.

محدودیت‌ها:
- این بسته APK نیست؛ سورس کامل پروژه است.
- ساخت موفق APK و آزمون روی دستگاه در این محیط تأیید نشده است.
- مجوز فعلی عمداً تغییر نکرده است.
- نقش‌ها و مجوزهای محلی، مرز امنیتی سروری محسوب نمی‌شوند.
- پیش از انتشار، باید GitHub Actions و سپس نصب/ارتقای برنامه روی یک نسخه پشتیبان از داده‌ها آزمایش شود.
