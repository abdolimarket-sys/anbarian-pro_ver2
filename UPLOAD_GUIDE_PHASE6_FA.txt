راهنمای اعمال مرحله ششم
1) ابتدا از مخزن GitHub نسخه پشتیبان/Release بگیر.
2) فایل‌های این ZIP را در شاخه اصلی مخزن بارگذاری و فایل‌های هم‌نام را جایگزین کن.
3) مطمئن شو GitHub Actions اجرای npm ci و npm run build را انجام می‌دهد.
4) برای APK، پس از build وب، npx cap sync android اجرا شود.
5) APK خروجی را روی یک نسخه آزمایشی و با حفظ داده‌ها تست کن؛ نسخه نصب‌شده باید با همان کلید امضا شده باشد.
