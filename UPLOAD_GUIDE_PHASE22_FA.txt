فاز ۲۲ حسابداری انبارین

۱) ابتدا از نسخه فعلی برنامه و داده‌های آن پشتیبان بگیرید.
۲) ZIP را در پوشه‌ای جداگانه استخراج کنید؛ روی نسخه اصلی بازنویسی نکنید.
۳) در محیط توسعه اجرا کنید: npm install
۴) آزمون‌ها: npm test
۵) بررسی TypeScript: npm run typecheck
۶) ساخت وب: npm run build:web
۷) نسخه آزمایشی را ابتدا در مرورگر و سپس در APK روی دستگاه جداگانه بررسی کنید.

امکانات: پرونده مشتری/تأمین‌کننده، فاکتور چندردیفی خرید و فروش، ثبت پیش‌نویس و قطعی‌سازی، دریافت و پرداخت صندوق/بانک و اسناد حسابداری خودکار.

محدودیت: این فاز هنوز موجودی انبار را تغییر نمی‌دهد؛ اتصال موجودی و بهای تمام‌شده در فاز ۲۳ انجام می‌شود. نرخ مالیات ثابت نشده و مبلغ مالیات باید توسط کاربر مجاز وارد شود. این بسته APK نیست و قبل از استفاده عملیاتی باید توسط حسابدار بررسی شود.
